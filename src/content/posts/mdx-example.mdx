:::tip
[Firefly](https://github.com/CuteLeaf/Firefly) 支持 `MDX` 和 `Markdown` 兩種類型的文章，你可以在文章中混合使用兩種格式，如果沒有特別複雜內容和需求，推薦使用 Markdown 格式就夠了。
:::

## Markdown 和 MDX 的區別
- Markdown (MD) 是一種輕量級標記語言，允許用戶使用純文本格式編寫文檔，然後將其轉換為格式化的HTML。它因其簡潔易用的語法而廣受歡迎，特別適合編寫文檔和博客文章。
- MDX 是一種擴展了 Markdown 語法的格式，允許在 Markdown 文檔中無縫地插入 JSX 代碼。通過 MDX，用戶可以在文檔中嵌入 React 組件，從而實現更豐富的交互性和動態性。

| 特性 | Markdown | MDX |
| :--- | :--- | :--- |
| 基礎語法 | 支持 (CommonMark) | 支持 (CommonMark) |
| HTML 標籤 | 支持 | 支持 (作為 JSX) |
| 組件導入 | 不支持 | 支持 (import) |
| 動態數據 | 不支持 | 支持 (JS 表達式) |
| 樣式定製 | 有限 (class/style) | 靈活 (className/CSS-in-JS) |

## Firefly 內置的專屬 MDX UI 組件
這裡列出 Firefly 內置的 MDX UI 組件，方便在 MDX 文章中直接使用。

### Tab分組：`TabGroup`
用於創建可切換的標籤頁，方便在文章中展示不同語言或不同版本的代碼等等。
````mdx
<TabGroup labels={["test.js", "test.py"]} client:load>
  ```js
  console.log(1)
  ```

  ```py
  print("hello world")
  ```
</TabGroup>
````
<TabGroup labels={["test.js", "test.py"]} client:load>
  ```js
  console.log(1)
  ```

  ```py

  ```
</TabGroup>

### 時間線：`Timeline` / `TimelineItem`

| 屬性 | 必填 | 說明 |
| :--- | :--- | :--- |
| `date` | 否 | 時間標籤，如 "2024-03-10" |
| `title` | 否 | 條目標題 |
| `type` | 否 | 節點顏色，default 為主題色，其餘對應提示框色板（tip / note / important / warning / caution） |
| `icon` | 否 | 內置圖標名，顯示在圓點內：star / rocket / git / flag / book / heart / zap / bug / tag / calendar / code / edit |
| 正文 | 否 | `<TimelineItem>` 標籤內的內容，支持 Markdown |

```mdx
<Timeline>
  <TimelineItem date="2026-08-16" title="新版本发布" icon="rocket">
    发布了全新版本，带来以下更新：

    - 新增时间线组件
    - 改进暗色主题

    正文里支持 **Markdown** 内容。
  </TimelineItem>
  <TimelineItem date="2025-11-02" title="站点上线" type="tip" icon="flag">
    欢迎来到我的博客。
  </TimelineItem>
  <TimelineItem date="2025-06-15" title="项目立项" type="note">
    开始规划 Firefly 主题。
  </TimelineItem>
</Timeline>
```

<Timeline>
  <TimelineItem date="2026-08-16" title="新版本發佈" icon="rocket">
    發佈了全新版本，帶來以下更新：

    - 新增時間線組件
    - 改進暗色主題

    正文裡支持 **Markdown** 內容。
  </TimelineItem>
  <TimelineItem date="2025-11-02" title="站點上線" type="tip" icon="flag">
    歡迎來到我的博客。
  </TimelineItem>
  <TimelineItem date="2025-06-15" title="項目立項" type="note">
    開始規劃 Firefly 主題。
  </TimelineItem>
</Timeline>

### 步驟條：`Steps` / `StepItem`

編號步驟條，適合教程、部署流程。編號自動生成，無需手動傳序號。

| 屬性 | 必填 | 說明 |
| :--- | :--- | :--- |
| `title` | 否 | 步驟標題 |
| `type` | 否 | 編號圓顏色，default 為主題色，其餘對應提示框色板（tip / note / important / warning / caution） |
| `icon` | 否 | 內置圖標名，有圖標時顯示圖標而非數字（star / rocket / git / flag / book / heart / zap / bug / tag / calendar / code / edit） |
| 正文 | 否 | `<StepItem>` 標籤內的內容，支持 Markdown |

```mdx
<Steps>
  <StepItem title="安装依赖">
    运行 `pnpm install`。
  </StepItem>
  <StepItem title="启动开发服务器" type="tip" icon="rocket">
    运行 `pnpm dev`，打开 `localhost:4321`。
  </StepItem>
  <StepItem title="编写文章">
    在 `src/content/posts/` 新建 `.mdx` 文章。
  </StepItem>
</Steps>
```

<Steps>
  <StepItem title="安裝依賴">
    運行 `pnpm install`。
  </StepItem>
  <StepItem title="啟動開發服務器" type="tip" icon="rocket">
    運行 `pnpm dev`，打開 `localhost:4321`。
  </StepItem>
  <StepItem title="編寫文章">
    在 `src/content/posts/` 新建 `.mdx` 文章。
  </StepItem>
</Steps>
